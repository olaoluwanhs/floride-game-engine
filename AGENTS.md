# Project Agent Guide

This is the Rust game-core repository. Start with [steering/README.md](steering/README.md), then follow the shared rules in [steering/constitution.md](steering/constitution.md) and [steering/learning-workflow.md](steering/learning-workflow.md).

For technical architecture, dependencies, and milestone details, use [docs/Rust_Game_Core_Architecture.md](docs/Rust_Game_Core_Architecture.md) as the source of truth. Read [steering/technical-baseline.md](steering/technical-baseline.md) for the short version of the agreed approach.

Before editing files or running state-changing project commands, explain the exact proposed actions and wait for the user's explicit go-ahead. If the user asks what to do, how to start, or asks only for planning or an explanation, give the steps and stop without acting. Approval applies only to the described scope; ask again before expanding it.

Make guidance actionable for a learner: name the exact files, summarize the intended code changes, provide literal terminal commands when useful, explain what each command does, and describe the expected result. Clearly distinguish steps the user can perform from actions the agent is proposing to perform.
